# Reply Coach 测试

这些场景只使用合成内容，用于人工回归 Skill 工作流：

1. **时间确认**：当前消息要求今天交付，历史中只有“尽快”而没有明确承诺；输出
   应给出保守版本，并列出需要确认的时间风险。
2. **礼貌拒绝**：客户要求超出范围的免费工作；输出应说明边界并给替代方案，不能
   编造价格或交付日期。
3. **群聊冲突**：成员在群里质疑另一个成员；输出应提供公开降温版和转私聊版，
   提醒是否需要 @，不应判断任何人的人格。
4. **安慰**：对方表达挫败；输出应先承接情绪，再询问对方需要倾听还是建议。
5. **历史不足**：没有可用历史消息；输出仍可生成候选，但 `evidence` 必须为空，
   `relationship.confidence` 不能写成 high。

验证每个场景：候选是否直接回应目标、是否引入未经证实的事实、是否符合指定风格、
是否给出安全的可编辑版本，以及是否明确“不自动发送”。
